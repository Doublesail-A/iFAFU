# iFAFU 1.1.0 · 日程与统一倒计时

## 使用变化

- 打开应用的首个实际界面即请求通知权限，并引导打开系统“闹钟和提醒”权限。已拒绝的请求不反复弹出，可从侧栏重新开启。
- 首页与小组件共用 `TodaySchedule`。课前显示“x分钟后上课”，课程进行中显示“x分钟后下课”，到实际结束才移除；取消旧的十分钟保留规则。筛选、倒计时取整、15 分钟警示使用同一实现。
- 冷进程启动即按缓存重绘，每次回到应用立即重绘小组件并刷新事件缓存；保留亮屏分钟更新、重复帧去重和熄屏不唤醒策略。最窄布局支持较长倒计时的单行字号适配。
- 加号打开“添加项目”，默认“添加日程”，旁边可切换“添加课程”。课程表单保留原有选项。
- 日程支持日期及自动星期、当天起止时间、事项、地点、备注，以及七种预设色或自定义 `#RRGGBB`。可点击编辑、删除。
- 日程独立保存于 Room，不受教务刷新、学校统一放假和补课规则影响；纳入首页、小组件、15 分钟本地提醒及日历导出。
- 课表按实际时分定位项目。课程与日程重叠时使用并排圆角布局，日程占较窄一栏；无重叠时使用整列宽度。早晚及学期外日期的日程也可以显示。

日程目前是指定日期内的一次性安排；课程仍使用教学周与节次设置。原有学校校历编排规则没有改成逐年日期特判。

## 工程与验证

- 数据库 18→19 只新增日程表及账号索引；设备测试验证原课程保留、日程账号隔离和删除。
- 40 项 JVM 回归测试通过，涵盖校历、教务解析、颜色、事件导出、更新、共享倒计时、日程日期和重叠分栏。
- 独立 Android 15 设备验证了表单默认选项/切换/保存、原生课表重叠布局、浅深色多尺寸及长标签、小组件实际分钟递减、已上课超过十分钟时保留并在结束时交接，以及无精确闹钟权限的分钟广播补充。
- 确认应用进程不存在且手机熄屏，跨过开课时刻后点亮手机，系统回调完成后宿主缓存已经显示下课倒计时，没有打开应用界面。测试读取前需让系统亮屏回调完成，避免启动 instrumentation 抢先中止尚在派发的回调。
- 本机日历重复导入、统一假期事件管线和课程/考试系统通知回归通过。启动通知权限弹窗和准时闹钟设置跳转也已实际检查。
- Debug 与混淆 Release 均构建成功，APK 完成签名验证。

系统授权仍由用户在手机上完成。精确闹钟未获准时或系统强行停止应用后，不能承诺所有后台状态均准时；需要在系统中授权或重新打开应用。组件熄屏时不逐分钟唤醒手机。
